# Computer Science Division

## Hackathon Project README

---

##  Project Overview

This project is a **modern, fully responsive departmental website** built for the **Stellenbosch University – Computer Science Division**.

It is designed as a **comprehensive institutional hub** that serves multiple stakeholders:

*  Prospective students
*  Current students
*  Alumni
*  Academic staff
*  Industry partners

The platform showcases academic programmes, research initiatives, departmental people, engagement channels, and industry-aligned news — all within a scalable and accessible design system.


#  Technical Architecture

##  Core Stack

* **Static HTML5**
* **Tailwind CSS**
* Custom global design system
* Vanilla JavaScript (for interactivity)
* SVG icons
* Google Maps integration (JS + iframe fallback)


##  Browser Compatibility

Designed for **maximum cross-browser reliability**, including:

* Chrome
* Firefox
* Safari
* Edge
* Internet Explorer 10+

### Compatibility Techniques

* Vendor-prefixed Flexbox:

  * `-webkit-`
  * `-ms-`
* Cross-browser CSS resets
* Graceful degradation
* JavaScript fallback strategies


##  Responsive Strategy

*  Mobile-first layout
*  Fluid responsive grids
*  Multi-column desktop layouts
*  Responsive data tables with alternating rows
*  Fixed header & footer
*  Scrollable content sections
